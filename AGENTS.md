# AGENTS.md — Pet Charm

Você está editando a landing page da Pet Charm Estética Animal. Antes de mudar qualquer coisa:

1. Leia `.agent/rules/` (todas as regras são obrigatórias).
2. Para tarefas comuns, siga a skill correspondente em `.agent/skills/`:
   - mudar textos, serviços, estilos de tosa, telefones → `petcharm-conteudo`
   - adicionar/trocar fotos → `petcharm-imagens`
   - publicar o site → `petcharm-publicar`
3. O site é estático: não adicione frameworks, bundlers ou bibliotecas sem pedido explícito.
